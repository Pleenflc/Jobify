# Jobify
This project is an AI Job Assistance website that helps job seekers prepare for their career journey. It provides tools such as an interview simulator with AI feedback, job matching based on the user’s skills, and a CV analyzer. The website also offers helpful tips to guide users in improving their job applications.

How to Run the Project
1. Install XAMPP
Download and install XAMPP.

2. Start Server
Open XAMPP Control Panel and start Apache

3. Move Project Folder
Copy the project folder into:
C:\xampp\htdocs

4. Run in Browser
Open your browser and go to:
http://localhost/Jobify
or:
http://localhost/Jobify/index.php
